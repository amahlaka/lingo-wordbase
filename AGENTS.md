# Lingo word base

Data only: JSON word lists for the Lingo games. Before adding or changing
entries, read [AUTHORING.md](AUTHORING.md) (what to write, levels, metadata)
and [README.md](README.md) (file format). New entries are English (US) and Finnish
only. Validate with `node scripts/check-content.mjs
path/to/lingo-wordbase` in a lingo-hangman checkout.
